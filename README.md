## 📚 Topics Covered

### ✅ NumPy — `numpy_basics.ipynb`
> The foundation of numerical computing in Python.

| Concept | Description |
|---|---|
| `np.array()` | Create a basic 1D array |
| `np.linspace()` | Generate evenly spaced values between a range |
| `np.zeros()` | Create an array filled with 0s |
| `np.ones()` | Create an array filled with 1s |
| `np.random.randn()` | Random values from normal distribution |
| `np.random.randint()` | Random integers within a range |
